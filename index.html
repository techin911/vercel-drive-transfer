📋 Setup Guide — Enable Google Drive (2 min) ▼
1
Go to console.cloud.google.com → New Project → name it DriveTransfer
2
Go to APIs & Services → Enable APIs → search Google Drive API → Enable
3
Go to APIs & Services → Credentials → Create Credentials → OAuth 2.0 Client ID
Type: Web application
Add Authorized JavaScript Origin: https://vercel-drive-transfer.vercel.app
4
Copy your Client ID → click ⚙️ Settings above → paste → Save
Then click Connect Google Drive → sign in → you're ready!
✅ Files go directly from your browser to Google Drive using the official API. No file size limit beyond Drive's own 5 TB limit. No third-party server involved.
